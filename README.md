## 🧭 About This Web Portal

This repository serves as the official **GitHub Pages deployment repository** for the [AI & Machine Learning Club](https://github.com/AIMLCLUBOCT) of Oriental College of Technology (OCT), Bhopal.

### 🌟 Key Highlights:
- 🚀 **12 Progressive Learning Modules:** Directly linking to our open-source curricula in [`learning_resources`](https://github.com/AIMLCLUBOCT/learning_resources).
- 📓 **Interactive Workshops Hub:** 1-click Google Colab launch buttons for our hands-on Python, Data Science, ML, and NLP notebooks in [`Workshops`](https://github.com/AIMLCLUBOCT/Workshops).
- 🛠️ **Starter Projects Showcase:** Featured initiatives with dual-mode zero-dependency execution in [`Projects`](https://github.com/AIMLCLUBOCT/Projects).
- 🎤 **Historical Event Archives:** Documentation and media links for technical bootcamps and conventions in [`EVENTS`](https://github.com/AIMLCLUBOCT/EVENTS).
- 📱 **Fast & Mobile-Responsive:** Built with modern vanilla HTML, CSS glassmorphism, and vanilla JavaScript without heavy framework bloat.
- 🔍 **SEO Optimized:** Full OpenGraph social cards, JSON-LD structured data schemas, XML sitemaps, and robots.txt.

## 🛠️ Local Development & Preview

```bash
# Clone the repository
git clone https://github.com/AIMLCLUBOCT/AIMLCLUBOCT.github.io.git
cd AIMLCLUBOCT.github.io

# Serve locally with any static web server
# Python 3
python -m http.server 8000

# Or with Node.js
npx serve .
```

Navigate to `http://localhost:8000` in your web browser.
