00 // EDITORIAL IDENTITY & MANIFESTO

We Don't Just Study AI.
We Build with It.

Surface-level tutorials cannot prepare engineers for production reality. We enforce mathematical foundations, zero-dependency algorithm rebuilds, strict peer review, and continuous deployment.

PHASE 01 // FOUNDATION

Mathematical Rigor

Mastering matrix calculus, eigenvalues, probability distributions, gradient descent convergence, and loss function geometry before invoking high-level frameworks.

NumPy • SymPy • SciPy
PHASE 02 // RECONSTRUCTION

Zero-Dependency Rebuilds

Implementing fundamental algorithms from scratch—linear regression, k-nearest neighbors, naive Bayes, and multilayer perceptrons—using pure Python and analytical calculus.

Pure Python 3.12+ • Pure Math
PHASE 03 // DEEP LEARNING

Production Frameworks

Accelerating architectures with PyTorch tensors, autograd, GPU acceleration, and Scikit-Learn pipelines. Training reproducible models with strict cross-validation.

PyTorch • Scikit-Learn • CUDA
PHASE 04 // SERVING

Inference & Optimization

Packaging model weights into ONNX runtimes, building sub-20ms FastAPI microservices, implementing token streaming, and containerizing pipelines for Kubernetes deployment.

FastAPI • Docker • ONNX Runtime
PHASE 05 // RIGOR

Peer Review & PR Audit

Every student pull request undergoes automated linting, test coverage checks, and rigorous review by club technical leads before merging into production.

GitHub Actions • Ruff • Pytest
PHASE 06 // ECOSYSTEM

Open Source Impact

Publishing benchmark studies, dataset releases, Colab tutorials, and reusable starters to empower the next generation of engineers across Central India.

MIT License • Hugging Face Hub

01 / 04 STABLE RELEASE

Campus Phishing Email Detection System

The Threat: Collegiate networks frequently suffer credential harvesting attacks targeting university student portals and fee gateways.

The Solution: A dual-mode text classifier using TF-IDF tokenization combined with Multinomial Naive Bayes. Includes a pure Python zero-dependency mathematical fallback module for offline embedded devices.

Scikit-Learn FastAPI Pure Python Math Pytest
Inspect Architecture Dual-Mode Fallback Enabled
02 / 04 STABLE RELEASE

Student Academic Performance & Risk Predictor

The Problem: Identifying at-risk engineering undergraduates before end-of-semester university examinations allows early academic intervention.

The Solution: A tabular regression and classification model analyzing internal assessment scores, laboratory attendance, and study hours. Features an analytical gradient descent fallback engine.

Random Forest Gradient Descent Pandas CSV Pipelines
Inspect Architecture R² Score: 0.91
03 / 04 ACTIVE LAB

Construction Safety Helmet & PPE Real-Time Vision

The Problem: Industrial manufacturing and campus construction sites require strict personal protective equipment compliance to prevent injuries.

The Solution: Fine-tuned YOLOv8 neural network trained on hard-hat and vest datasets, optimized with ONNX Runtime to maintain 45 FPS on edge video streams.

YOLOv8 OpenCV ONNX Runtime PyTorch
Inspect Architecture Edge Speed: 45 FPS
04 / 04 ACTIVE LAB

Campus Ordinance Semantic RAG Assistant

The Problem: University syllabi, exam rules, and college notifications span hundreds of unstructured PDF pages, making student inquiry tedious.

The Solution: Hybrid BM25 keyword + dense vector semantic retrieval system over official OCT documents with citation tracking and hallucination guardrails.

LangChain pgvector FastAPI SentenceTransformers

03 // RESEARCH

ASK. EXPERIMENT. MEASURE.

Moving beyond theoretical speculation. Our student researchers conduct empirical replications, model quantizations, and inference efficiency audits.

EXP-01 // QUANTIZATION OCT-LAB 2026

Edge Latency vs INT8 Quantization Loss

Quantizing ResNet-50 and YOLOv8 weights from FP32 to INT8 via ONNX Runtime to evaluate mAP degradation against inference frame rate gains on low-power Intel Celeron and Raspberry Pi edge devices.

PRECISION FPS (CPU) mAP@50 SIZE
FP32 Original 12.4 88.2% 98 MB
INT8 Quantized 38.7 (3.1x) 86.9% (-1.3%) 26 MB (-73%)

MediaPipe Landmark Occlusion in Low-Light Classrooms

Evaluating 33-point pose landmark estimation drift under fluctuating ambient illumination (50–300 lux) and classroom desk occlusions for student posture analysis.
